# Python GUI Calculator

A simple calculator application using Python's `tkinter` library. It provides basic arithmetic operations and displays a pop-up window with an interactive calculator interface.

## Requirements

- Python 3.x (Tkinter should be included by default)

## Running

To start the calculator, run:

```bash
python calculator.py
```

## Features

- Addition, subtraction, multiplication, division
- Clear and equals functionality
- Pop-up window with GUI interface
